# ras-minimal — минимальный Docker-образ сервера RAS 1С

Служба администрирования RAS для dev/тест-стенда. **Бинарные файлы платформы 1С в репозиторий
не коммитятся** (проприетарная лицензия 1С) — их нужно получить из дистрибутива платформы
самостоятельно: скачать с [releases.1c.ru](https://releases.1c.ru) (нужен аккаунт линии
назначения 1С) архив платформы 8.3 для Linux x86_64 и распаковать.

Подготовка контекста сборки (версия 8.3.25.1520; при другой версии — синхронизируйте путь
в `Dockerfile` и `docker-entrypoint.sh`):

```bash
# из распакованного дистрибутива скопируйте каталог платформы как есть:
mkdir -p bin conf
cp -r <distro>/opt/1cv8/x86_64/8.3.25.1520/* bin/
# bin/ должен содержать ras, *.so, *.res, conf/ платформы
cp <distro>/opt/1cv8/conf/* conf/   # при необходимости (logcfg.xml и др.)

docker build -t ras-minimal .
docker run -d -p 1545:1545 -e RAS_CLUSTER_ADDRESS=ragent:1540 ras-minimal
```

Этот образ используется тестовым стендом RAS (`1c-test-server`) в dev-сети.
